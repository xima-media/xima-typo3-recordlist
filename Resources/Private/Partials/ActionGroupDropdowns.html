Standalone dropdown shells, rendered server-side so they sit at their final size on first paint (no flicker, no layout shift). Each shell declares its group via `data-action-group-menu`; recordlist-action-groups.js relocates every bar action marked `data-action-group=""` into the matching menu, and recordlist.css hides a shell when the row has no action of that group (presence-based `:has`). Add a group: add a shell here with a unique `data-action-group-menu`, tag the actions with the matching `data-action-group`, and add the presence-hide rule in recordlist.css.
